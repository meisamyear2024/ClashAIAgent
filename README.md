# Clash AI Agent

A small Android launcher app with a custom AI-themed icon. Tapping it launches the installed Clash of Clans app.

## Important
This app does not control or automate gameplay. It only launches Clash of Clans.

## Build
Open this folder in Android Studio, let Gradle sync, then:
Build > Build App Bundle(s) / APK(s) > Build APK(s)

Install the resulting APK on the Android phone.

Package: com.meisam.clashai
Target app package: com.supercell.clashofclans
